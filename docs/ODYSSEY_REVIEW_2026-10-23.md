## EPUB 표준 및 읽기 환경 검토

- 기존 오디세이아도 EPUBCheck를 통과하는 일반 EPUB 3였다. 재검토에서 펌웨어 전용 형식이라는 근거는 발견되지 않았다.
- 2026-10-23 현재 W3C의 EPUB 3.3은 권고이며, EPUB 3.4는 2026-10-20 후보 권고 초안이다. 교정본은 안정된 EPUB 3.3을 기준으로 ZIP/미디어 유형, XML, OPF, manifest, spine, 목차, NCX, 내부 링크와 자원, 대역 개수를 검사했다. 패키지의 version="3.0"은 EPUB 3 계열에서 사용하는 표준 값이다.
- 원문 grc, 번역 ko 선언을 확인하고 한국어 목차·책 제목의 언어 선언을 보완했다. 표준 목차와 호환용 NCX에 저본 안내를 함께 넣고 순서를 일치시켰다.
- 원문과 번역을 모두 표시하며 JavaScript, 전용 언어 토글, 내장 폰트, 기기별 파서를 요구하지 않는다. 그리스어는 일반 시스템 폰트의 대체 순서만 보완했다.
- 안내 페이지의 긴 해시가 좁은 화면 밖으로 넘치는 현상을 CSS 줄바꿈으로 수정했다. 시와 원문의 행 구조를 보존했다.
- 최종 공식 EPUBCheck 5.4.0의 EPUB 3.4 규칙 검사도 통과(오류·경고 0건). 일반 렌더러에서 저본 안내와 24권을 폭 320px·본문 24px 조건으로 검사하고, Calibre 변환도 확인했다. 이는 모든 기종의 표시를 실기 검증했다는 뜻은 아니다.
