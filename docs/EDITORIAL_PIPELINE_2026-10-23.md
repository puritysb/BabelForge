# 오디세이아 교정 결과를 일반 파이프라인에 반영

## 발견한 원인과 반영 내용

| 교정에서 드러난 원인 | 일반화한 처리 |
|---|---|
| 장면에 맞지 않는 사전 뜻, 동작 주체·조건문·비교 관계의 뒤바뀜, 원문에 없는 친족·사물의 추가 | 초벌 번역·교열·최종 검수가 공유하는 원문 충실성 기준을 적용한다. 다의어, 주객 관계, 부정, 시간, 물리적 사실, 별칭·말장난, 한국어 문법을 각각 확인한다. 특정 작품의 단어 치환표는 넣지 않는다. |
| 구간 밖의 내용을 보충하거나 계속되는 문장을 중복 번역 | 장 경계와 빈 장을 건너 인접 원문·번역을 문맥 자료로 제공하며 번역 범위는 해당 원문으로 제한한다. 저본의 누락을 기억이나 다른 판본으로 채우지 않는다. |
| 검수기가 고친 문장을 같은 응답에서 승인 | 수정은 미승인 제안으로 저장한다. 제안자의 사유를 넘기지 않는 별도 호출에서 최종 문구에 명시적인 `keep`이 있어야 승인한다. 재수정도 다시 검수한다. 최대 네 차례 내에 수렴하지 않으면 실패한다. |
| 근거를 잘못 인용하거나 없는 활용형을 인용 | 의미 교정은 사유와 실제 원문 인용을 요구한다. 한국어 문법·철자 교정만 인용 생략을 허용한다. 인용 대조는 NFC·생략 부호와 행 머리의 권·행 번호만 정규화하며, 악센트·활용형을 느슨하게 맞추지 않는다. |
| 올바른 문장이 단순 문체 취향 때문에 계속 바뀜 | 정확한 문구 유지 원칙을 공통 적용하고, 반복 `correct`를 승인으로 간주하지 않는다. 교정기가 올바른 내용을 망가뜨린 경우도 다음 검수에서 회복할 기회를 갖는다. |
| 금지 표기가 다른 단어나 다른 지시 대상에 포함됨 | 용어 검수에도 작품·인접 원문을 제공한다. 인명/지명/직업/보통명사와 다의어를 구별하고, 원문 관용구의 발생 위치 검증을 유지하고 한국어 금지 표기의 예외도 발생 위치 단위로 좁힌다. 반복된 표기는 각각 `ko_start` 또는 출현 순번 `ko_occurrence`를 지정해야 한다. 따라서 아카이오스인 속 이오스의 허용이 같은 문단의 잘못된 여신 이름까지 면제하지 않는다. 부분문자열을 기계적으로 전역 치환하지 않는다. |
| 배치의 일부만 잘못되어 정상 판정까지 사라짐 | 정상 행은 즉시 적용·저장하고 누락·중복·비정상 행만 최대 세 번 재요청한다. JSON 코드 펜스를 복구하며, 근거가 잘못된 교정은 적용하지 않는다. |
| 응답이 길어 잘리거나 재개 시 교정안이 승인으로 오인됨 | 문단 수, 직렬화한 입력 행 24,000자, 교정·근거 출력 예상량 6,000자를 함께 제한한다. 문자 예산은 토큰화의 근삿값이다. 승인 캐시에 최종 텍스트·원문·주변 원문·번역·작품·모델·품질 프로필을 묶는다. 이전 검수 버전 승인은 무효화한다. |
| 예상하지 못한 병렬 작업 오류로 다른 번역 결과도 저장되지 않음 | 완료된 번역 future를 모두 수거하고 정상 결과를 체크포인트에 보존한다. 실패한 빈 구간은 기존 완성도 검사에서 출판을 막는다. |
| EPUB 대역 수가 같으면 내용 유실도 통과할 수 있음 | 조립 직후와 발행 직전에 spine 순서의 원문·번역 가시 텍스트를 승인된 대역 전체와 대조한다. 목차의 원문/한국어에는 각각 언어를 표시한다. |

## 기록과 호환성

체크포인트 `audit_log`에 수정 전후 문구, 사유, 원문 인용, 입력·출력 서명, 검수 버전·모델·품질 프로필, 승인 여부를 보존한다. 아직 승인되지 않은 수정도 중단 후 다시 검수할 수 있다. 이미 승인된 같은 문장과 같은 문맥만 캐시로 생략한다. 교정으로 주변 한국어가 달라지면 이웃 구간도 다시 검수하여 대화체·중복 문장의 승인이 낡은 문맥에 묶이지 않도록 한다. 정상 응답 단위로 저장하므로 일부 응답 오류나 다음 네트워크 호출의 실패가 이전 정상 판정을 없애지 않는다.

초벌 프롬프트는 `literary-precision-v4-contextual-fidelity`, 최종 검수는 `semantic-v5-independent-approval`로 올렸다. 구버전 체크포인트를 새로운 기준으로 검수한 것으로 간주하지 않는다. 번역 지침 프로필까지 달라진 기존 체크포인트는 종전의 호환성 규칙에 따라 초벌부터 다시 처리한다. 기존 EPUB·오디세이아 교정본을 자동 변경하거나 라이브러리 전체를 재번역하지 않는다.

생성과 내용 검수는 일반 EPUB 3 계약을 유지한다. 전용 폰트·펌웨어·스크립트가 필요하지 않다. EPUB 가시 텍스트 비교는 마크업 해석 후 공백을 정규화한 비교이며, 바이트 단위 파일 동일성이나 모델의 번역 능력을 보증하는 검사가 아니다. 원문의 구조·행 구분 보존 검사는 기존 추출·템플릿·마크업 회귀 검사와 함께 수행한다.

## 검증 범위

`tests/test_editorial_review.py`는 교정 뒤 독립 승인, 교정 자체의 의미 퇴행, 반복 교정의 실패, 부분 응답 복구, 중복 판정 거부, 그리스어 인용의 Unicode/활용형 구별, 모델·용어 프로필 변경, 문자 예산, 장 경계의 문맥·한국어 변경에 따른 이웃 재검수, 다른 언어의 정상 문장 유지, EPUB 내용·순서 대조 및 목차 언어를 검증한다. 한국어 예외의 범위 제한, 반복 발생의 별도 지정, 올바른 충돌 표기를 이동한 교정도 회귀 사례에 포함했다. 기존 중단/재개 테스트도 미승인 수정안이 다시 검수되는지와 기록 보존을 확인하도록 강화했다.

테스트는 모델 응답을 모의한다. 실제 모델이 모든 언어의 오역을 검출한다는 평가 결과는 아니며, 외부 API 번역·출판·알림을 실행하지 않는다. 독립 검수는 별도 호출을 뜻하며 다른 모델이나 사람의 학술 교열을 뜻하지 않는다.

초기 개선 당시 검증: `./venv/bin/python3 -m unittest discover -s tests` — **171개 테스트 통과** (2026-10-23, 89.355초). 신규 교정 회귀 사례는 20개다. 테스트가 출력한 의도적 네트워크·교정·발행 실패 사례도 모두 예상한 예외 경로로 확인했다. `git diff --check`도 통과했다.


## 기존 번역본에 적용하면서 추가한 보완

후속 요청에 따라 전체 기존 번역본의 재검수를 별도 작업으로 수행한다. 위의 “자동 변경하지 않는다”는 초기 일반화 작업의 범위를 설명한다. 명시적인 전체 재검수는 `review_library.py`와 `finish_library_review.py` 절차를 사용한다.

- 보관된 TXT 저본과 순서대로 정확히 정렬하여 누락된 짧은 대사·번호·문단을 복원한다. 저본이 맞지 않으면 유사 정렬로 통과시키지 않는다. 기존 한국어를 재사용할 수 없는 구간만 다시 번역한다.
- 짧은 숫자·로마 숫자 표제에 다음 문단이 섞인 오류, 소스에 없는 배치·태그 표식을 무결성 검사에서 차단한다. `J. M.` 같은 저자 이니셜은 문장이 아닌 식별자로 보존한다. 숫자뿐인 원문은 해당 숫자를 교정 근거로 인용할 수 있다.
- 용어 정규화에서 통계 후보 길이 제한 때문에 두 글자 일본어 이름이 사라지지 않도록 한다. 한자 이름의 독음은 원전의 후리가나를 우선하며, 일반 단어·이름 말장난에는 문맥을 적용한다.
- 선택된 중역 판본을 대조할 때 다른 원어 판본의 표현을 강제로 덮어쓰지 않는다. 예를 들어 영어판의 가족 문맥에 쓰인 `wife and child`는 ‘아내와 아이’이며, 독일어 제목의 별도 번역이 이를 바꿀 근거가 되지 않는다.
- 서로 다른 원어가 같은 한국어 표기와 충돌하면 각각의 출현 위치·근거 표현으로 분류한다. 모델에 출현 순번과 주변 문구를 제공해 반복된 정당한 표현을 한 문단짜리 예외로 뭉뚱그리지 않게 한다.
- 의미 교정 과정에서 새로 빠진 인용 부호 경계는 최종 포장 전 별도 확인한다. 정당한 한국어 인용 방식은 원문과 대조한 이유 및 최종 문구 해시로 기록하며, 실제 누락은 미승인 교정 후 독립 재검수한다.
- 기존 파일은 보존하고 교정본은 별도 경로에 생성한다. 최종 전달 전에 승인된 대역 전체와 내용 대조, 시의 명시적 줄바꿈·장 목차 복원, 공식 EPUBCheck를 수행한다.

후속 공통 변경 검증: 전체 **193개 테스트 통과**(2026-10-24, 39.441초), `git diff --check` 통과. 실제 판본별 모델 검수·교정 수와 EPUB 검사 결과는 전체 재검수 완료 보고서에서 별도로 집계한다.


실제 전체 재검수에서 추가로 확인한 두 경로도 차단했다. 응답 본문 읽기의 직접적인 `TimeoutError`·연결 오류는 기존의 제한된 네트워크 재시도 절차로 처리하고, 미완성 응답을 승인으로 쓰지 않는다. 또한 옛 `Mr.`/`Mrs.` 등의 약어에서 분리된 두 번역 구간에 같은 한국어 이름이 중복되면 최종 전달을 막는다. 이는 원문과 이어 읽기를 다시 확인하라는 검사이며 자동 문구 치환은 아니다.


긴 블록을 문자 예산으로 강제 분할할 때도 기존 약어 목록을 적용한다. `Mr.`·`Mrs.`·`Dr.`를 문장 끝으로 고르거나 그 바로 뒤의 공백을 분할점으로 고르는 일을 막아 이름과 관계절이 끊기지 않게 했다. 회귀 검사는 문자·공백을 하나도 버리지 않으면서 예산을 지키고, 일반/문장 단위 모드 모두에서 호칭과 이름을 함께 보존하는지 확인한다. 이미 고정된 재검수 원문의 구간을 몰래 바꾸지는 않으며, 기존 경계 네 곳은 실제 원문과 이어 읽기로 별도 대조했다.


검수 모델이 올바른 교정을 다시 오역으로 되돌리는 사례에는 출처가 있는 어휘·문법 근거를 제공한다. 근거는 원문 바이트의 SHA-256에 연결하여 해당 구간에만 전달하고, 근거 내용도 승인 서명에 포함한다. 원문이나 근거가 달라지면 기존 승인을 재사용하지 않는다. 제안자의 교정 사유와 별개인 참고 자료이며, 근거가 있어도 명시적인 별도 `keep`은 필요하다. 오디세이아의 궤짝/갈고리, 양옆에 한 명씩인 시녀, 뿌리박힌 침대 기둥 사례로 적용했고, 적용 범위·승인 무효화·체크포인트 왕복 보존을 회귀 검사했다.
