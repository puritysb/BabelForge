# 번역·검수·발행 파이프라인 최종 코드 리뷰

2026-10-24 기준으로 작업 트리의 번역·검수·표준 EPUB·발행 변경 전체를 검토하고 재현한 문제를 수정했다. 이번 리뷰는 코드와 실패·재시도 경로의 검증이며, 기존 번역문을 다시 생성하거나 운영 라이브러리를 재발행하지 않았다.

## 수정한 문제

| 경계 | 발견한 문제와 수정 |
|---|---|
| 번역 체크포인트 | 헤더의 원문 해시·프로필만 같으면 실제 저장된 원문 배열이 달라도 한국어를 재사용할 수 있었다. 각 구간의 원문·순서·쌍 형식을 확인한 뒤에만 재사용한다. |
| 검수 승인 | 개념표를 수정하고 예전 `profile_hash`를 남긴 경우를 별도로 차단하지 않았다. 프로필 해시를 재계산해 확인하고, 기준 데이터 파일의 해시와 원문 배열도 체크포인트와 대조한다. |
| 용어 검수 응답 | 중복 판정의 첫 행을 고르거나 소수·문자열·불리언 인덱스를 정수로 강제 변환할 수 있었다. 의미 검수와 마찬가지로 정확히 한 행과 실제 정수 인덱스만 허용한다. |
| 원문 캐시 | 같은 URL의 후속 다운로드가 이미 다른 작업에 전달한 파일 내용을 교체할 수 있었다. 새 파일은 내용 해시 기반 경로에 저장하고 메타데이터가 그 파일을 가리키게 했다. 예전 캐시는 계속 읽을 수 있다. |
| EPUB 리소스 | XHTML에만 실행 코드 검사를 적용해 별도 SVG 파일의 스크립트·이벤트 속성이 빠질 수 있었다. SVG도 발행 전 같은 검사를 거친다. |
| 발행 완료·재시도 | 구판 삭제 전에 `published`가 돼 정리 실패 시 재시도가 막힐 수 있었다. 정리 전에는 완료 상태로 표시하지 않고, 끝난 뒤에만 발행 완료로 전환한다. 같은 교정 명령이 기존 요청을 찾아 재개한다. |
| 동시성·소유권 | CLI 발행도 요청 작업 잠금을 소유하게 했다. 기존 파이프라인의 잠금은 재사용한다. 다른 판본의 목적지 덮어쓰기와 구판 경로의 새 소유자를 차단하고, 로컬 원문 경로를 다른 내용으로 재사용한 경우도 알려진 원문 해시로 구별한다. |
| 서버 중단 복구 | 서버를 내린 뒤 프로세스가 강제 종료되면 `finally`가 실행되지 않아 재시작할 수 없었다. 중지 전에 유지보수 표식을 기록하고 다음 발행이 동일한 설정의 해당 서비스만 복구한다. 수동 중지된 무관한 서비스는 시작하지 않는다. |
| 명시적 EPUB 입력 | 외부 경로의 EPUB을 발행할 때 목적지 제한 때문에 정상 입력까지 거부할 수 있었다. 사용자 파일을 보존하면서 관리 라이브러리로 가져오고, 삭제 범위 제한은 그대로 유지한다. |

관련 구현은 `translate.py`, `quality_audit.py`, `sources/download.py`, `epub_validate.py`, `review_library.py`, `publish_reviewed.py`, `publication.py`에 있다. 실행 절차 정본인 book-translator 스킬과 아키텍처 문서도 함께 갱신했다. 브라우저 자동화 로그는 `.gitignore`로 제외했다.

## 최종 검증

- `./venv/bin/python3 -m unittest discover -s tests` — **224개 테스트 통과**, 42.227초.
- 실패 응답·네트워크·Calibre·서버 제어·삭제 회귀는 모의 응답과 임시 디렉터리에서 실행했다. 의도적으로 발생시킨 오류 로그를 포함해 전체 테스트 결과가 성공임을 확인했다.
- `python -m compileall`과 `git diff --check` 통과.
- book-translator 스킬 유효성 검사 통과.
- 강화된 `publish_reviewed.py --check-only`로 기존 교정본 **6종 전체**의 승인·기준 데이터·프로필·산출물·EPUBCheck 사전 검사 통과.
- `.env`, 생성 EPUB, 캐시, 실제 검수 호출, 운영 카탈로그, 실행 로그는 커밋 대상에서 제외한다.

검증한 주요 실패 사례는 정리 도중 파일 변경/삭제 거부 후 재개, 같은 요청의 동시 재시도 차단, 이미 소유한 잠금 재사용, 다른 판본 목적지 보호, 검수 이후 파일 변경, 변조된 개념표·기준 원문, 중복 용어 판정, 다운로드 뒤 원문 캐시 변경, SVG 실행 코드와 서버 중단 표식 복구다.
