# 교정본 자동 발행 일반화 — 2026-10-24

기존 교정본 발행에 사용했던 개별 스크립트를 공통 발행 경로로 옮겼다. 사용자의 최종 정책에 따라 **구판 EPUB 백업은 생성하지 않는다**. 이번에 보관했던 백업 폴더 2개와 옛 번역 EPUB 사본 8개도 삭제했다. 삭제한 파일의 경로·해시는 `data/publications/retired-artifacts-deleted-2026-10-24.json`에 기록했다. 전체 삭제 대상은 백업 메타데이터·임시 다운로드 사본까지 포함해 65개 파일, 23,534,564바이트다. 최신 교정본 6종과 원문·검수 JSON 기록은 유지했다.

## 자동 처리

- `publish.publish()`와 일반 번역 파이프라인이 `publication.publish_revision()`을 사용한다. 검수본을 임시 파일로 고정하고 공식 EPUBCheck를 통과해야 Calibre를 변경한다. 일반 파이프라인은 승인한 파일 해시와 원문·번역 전체 구간도 넘겨 검수 이후의 파일 교체를 차단한다.
- 저본·출처 ID·원문 언어에 연결된 식별자로 기존 Calibre ID와 주소를 유지한다. 제목이 같아도 다른 저본·권·중역 판본은 합치지 않는다. 식별자 없는 과거 항목은 지정한 구판의 해시와 실제 다운로드 전체 내용을 먼저 대조해야 연결할 수 있다.
- 공개 OPDS의 실제 탐색 링크와 다음 페이지를 따라 해당 ID가 한 번 안내되는지 확인한다. 안내된 EPUB과 안정적인 다운로드 주소 양쪽에서 받은 파일을 원문·번역 전체 구간과 비교하고, 실제 공개 EPUB에 공식 EPUBCheck를 적용한다. Calibre 메타데이터 재작성 때문에 ZIP 바이트가 달라지는 것은 전체 내용 비교와 구별한다.
- 검증 이후 로컬 파일을 원자적으로 교체하고 카탈로그를 갱신한 뒤, 동일 식별자의 중복 레코드와 명시된 구판 파일만 삭제한다. 기준 Calibre 레코드는 삭제하지 않는다. 파일 삭제는 관리 라이브러리 안의 지정 경로·기록된 해시로만 하며, 심볼릭 링크·변경된 파일·다른 판본의 공유 경로는 차단한다.
- 공개 검증 실패 시 별도 구판·중복 삭제는 실행하지 않는다. Calibre 교체 후의 실패는 구판으로 롤백하지 않고 최신 검수본과 진행 기록을 남겨 같은 명령으로 재시도한다. 단계·해시 기록은 `data/publications/`에 남기며 구판 EPUB 자체를 보관하지 않는다.
- 관리 중인 읽기 전용 로컬 서버는 쓰기 작업 동안만 중지하고 `finally`에서 같은 설정으로 재시작한다. 쓰기를 위한 프로세스별 DB 대상만 변경하며, 공개 쓰기 권한이나 LaunchAgent 파일은 변경하지 않는다. 관리 서버가 아닌 경우의 쓰기 오류는 중단한다.

## 교정 manifest 발행

운영 절차의 정본은 `.agents/skills/book-translator/SKILL.md`다.

```bash
./venv/bin/python3 publish_reviewed.py manifest.json --check-only
./venv/bin/python3 publish_reviewed.py manifest.json
# 최종 포장과 발행을 함께 요청한 경우:
./venv/bin/python3 finish_library_review.py manifest.json --publish
```

`publish_reviewed.py`는 모든 판본의 현재 원문·한국어·이웃 문맥·프로필에 대한 승인 서명, 원문 해시, 교정본 파일 해시, 인용 부호 처리와 공식 EPUBCheck를 사전 검사한다. `completed` 표시만으로 발행하지 않는다. 기존 카탈로그의 출처와 요청 ID를 재사용하고, 없는 판본은 manifest의 `publication` 설정을 사용한다. 발행 완료 뒤 사라진 구판 파일 때문에 다음 검수본 발행이 막히지 않도록, 발행 검증은 보관된 승인 기록과 최종 산출물을 기준으로 한다.
